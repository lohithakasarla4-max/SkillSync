# 🚀 SkillSync – AI-Powered Resume & Job Matcher

SkillSync is a lightweight, AI-driven resume analysis tool that helps job seekers align their resumes with target job descriptions. By performing real-time keyword parsing and gap analysis, SkillSync gives candidates immediate feedback on how well their resume matches a job posting before submitting an application.

---

## ✨ Features

- **Match Score Calculation**: Generates an overall percentage match score between a candidate's resume and a target job description.
- **Keyword Gap Analysis**: Identifies overlapping skills while isolating critical missing keywords needed for Applicant Tracking System (ATS) optimization.
- **Interactive UI**: A clean, responsive dashboard built with Streamlit for quick side-by-side text analysis.

---

## 🛠️ Tech Stack

- **Language**: Python 3.13
- **Frontend / UI**: Streamlit
- **Data Processing**: Pandas, Regular Expressions (`re`)
